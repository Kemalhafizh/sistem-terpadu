# Rencana Implementasi Android

Dokumen ini dulu berisi salinan rencana aplikasi Android yang sudah tidak diperbarui. Satu-satunya sumber yang berlaku adalah [`android_implementation.md` di repo `Kemalhafizh/sista-android`](https://github.com/Kemalhafizh/sista-android/blob/main/android_implementation.md). Kontrak API yang dipakai aplikasi didokumentasikan di `docs/API.md` dan `docs/modules/` repo ini, dan perubahan endpoint mobile mengikuti aturan di `CLAUDE.md` (bagian Mobile API).
